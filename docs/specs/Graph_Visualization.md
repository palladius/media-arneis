# Track Specification: Implement dependency graph visualization using Mermaid.js

## Track Overview
This track focuses on adding a visualization feature to `arnectl`. It will enable users to generate a visual representation of the project's dependency graph using Mermaid.js syntax, which is natively rendered in GitHub and other Markdown viewers.

## User Stories
- **As a Media Creator,** I want to see a visual map of my project's chapters and their dependencies so I can understand the generation sequence.
- **As a Developer,** I want to generate a `graph.mermaid` or `DEPENDENCIES.md` file from a YAML specification.

## Functional Requirements
- **Graph Generation:**
  - Traverse the dependency graph generated by the `Orchestrator`.
  - Convert the task list and dependencies into Mermaid.js flowchart syntax (`graph LR`).
- **CLI Integration:**
  - `arnectl graph YAML_PATH`: Generate the Mermaid visualization for a given YAML.
  - Option to output to a specific file (e.g., `graph.md`).
- **Visual Enhancements:**
  - Use different node styles/colors based on task types (if available) or status (when running against an active project folder).

## Acceptance Criteria
- [ ] `arnectl graph rubycon_pitch.yaml` successfully generates a valid Mermaid diagram.
- [ ] The output correctly reflects the dependencies defined in the YAML.
- [ ] The generated diagram is readable and logically structured.
